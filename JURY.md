# Freedom Graph: запуск для жюри

Репозиторий содержит исходные данные кейса, рассчитанный граф, API и готовую сборку сайта. Отдельно запрашивать Parquet и собирать frontend не нужно. Для основного сценария не нужны ключи OpenAI или Telegram.

## 1. Самый простой запуск

Скачайте **весь репозиторий** через Code → Download ZIP и распакуйте либо клонируйте его. Откройте терминал в папке, где находится этот файл и `jury_start.py`. Для закрытого репозитория нужен доступ от владельца организации.

Нужен установленный Python 3.11+; проверка комплекта выполнена на Python 3.12. Первая установка зависимостей требует интернета. Если Windows пишет `Python was not found`, установите Python с [python.org](https://www.python.org/downloads/) и заново откройте терминал.

**Windows / PowerShell:**

```powershell
py -3.12 jury_start.py
```

**Linux / macOS:**

```sh
python3 jury_start.py
```

Скрипт создаёт `.jury-venv`, устанавливает зависимости и запускает сервер. Если в Linux отсутствует модуль `venv`, установите пакет `python3-venv` для своего Python. После успешной установки повторный запуск можно выполнить с `--skip-install` без обращения к установщику пакетов.

Откройте:

- основной сайт: **http://127.0.0.1:8000/**;
- проверку API: http://127.0.0.1:8000/check;
- демонстрационный Mini App: http://127.0.0.1:8000/miniapp/.

Терминал должен оставаться открытым; остановка — Ctrl+C. Если порт занят, добавьте `--port 8002` и откройте соответствующий адрес. `127.0.0.1` означает компьютер проверяющего, на котором выполнен запуск, и не является удалённой ссылкой на компьютер команды.

Проверить наличие сборки, снимка, шрифта PDF и соответствие Parquet контрольным суммам можно без установки зависимостей:

```powershell
py -3.12 jury_start.py --check
```

## 2. Что проверить за 3–5 минут

1. Откройте сайт. Ожидаются **2 248 узлов, 3 119 связей, 4 840 транзакций и 91 кластер**, период 1–31 июля 2026 года. Снимок: `20260923T123524Z-761e950f`.
2. Введите полный GID `100000008603629100` в поиск. Также существуют `100000000331309100` и `100000005910114100`. Откройте карточку, основания роли и соседей.
3. Выберите уровень «Критический»: граф показывает выбранные узлы с соседями и связи внутри этого окружения. Проверьте выбор ребра и его направление, сумму и даты.
4. В помощнике задайте «Выбери 10 приоритетных узлов». Без ключа ответ формируется **локально по правилам и фактам снимка**, а не языковой моделью. Доступны переходы к GID и сведения об инструментах.
5. Во вкладке расследования добавьте узел или связь в досье и скачайте PDF. Пустое досье сначала нужно наполнить. PDF формируется сервером из выбранных фактов; ключ AI не нужен. CSV результатов также доступны на сайте и через `/check`.
6. Переключите RU / KZ / EN. Кнопки интерфейса переведены; тексты методики, пояснения из данных и PDF остаются на русском.

Mini App по `/miniapp/` — отдельная демонстрация на синтетических данных. Она ещё не отображает этот реальный граф и не подтверждает сквозную интеграцию уведомлений Telegram. Для запуска основного сайта бот не требуется.

## 3. Проверка с внешней AI-моделью — по желанию

Скопируйте `backend/.env.example` в локальный `backend/.env`, задайте `OPENAI_API_KEY` и `OPENAI_MODEL` своей учётной записи. Затем остановите сервер и запустите:

```powershell
py -3.12 jury_start.py --skip-install --with-ai
```

В Linux/macOS замените `py -3.12` на `python3`. Обычный запуск явно выключает внешние AI-вызовы даже при наличии личного `.env`. С `--with-ai` помощник использует OpenAI при доступной модели; при отсутствии настроек или ошибке провайдера возвращается к локальному режиму. Выбранные факты и запрос передаются провайдеру, его вызовы могут тарифицироваться. Секретные ключи в репозитории отсутствуют.

## 4. Где лежат данные и как повторить расчёт

| Путь | Содержимое |
| --- | --- |
| `backend/data/*.parquet` | Три исходных файла кейса организаторов |
| `backend/jury_snapshot/LATEST` | Идентификатор готового запуска |
| `backend/jury_snapshot/runs/<run_id>/` | JSON графа, CSV, метаданные, отчёт качества, дополнительные анализы |
| `Frontend/dist/` | Готовая сборка основного сайта |
| `backend/assets/fonts/` | Шрифт PDF с кириллицей и его лицензия |

После установки зависимостей для повторного расчёта в Windows:

```powershell
.\.jury-venv\Scripts\python.exe -m backend.run_pipeline
.\.jury-venv\Scripts\python.exe -m backend.serve
```

В Linux/macOS используйте `.jury-venv/bin/python`. Сначала остановите предыдущий сервер. Новый расчёт сохраняется в `backend/output/`; `backend.serve` открывает его. Команда `jury_start.py` всегда открывает включённый в комплект `backend/jury_snapshot/`, чтобы обычная проверка не зависела от пересчёта и локального `.env`.

## 5. Docker — альтернативный запуск

При наличии запущенного Docker Engine / Docker Desktop:

```sh
docker compose up --build
```

Откройте http://127.0.0.1:8000/. Остановка: `docker compose down`. Образ включает данные, снимок и сборку сайта; локальный `.env`, личные ключи и состояние Telegram не копируются. Конфигурация подготовлена; сборка контейнера на компьютере команды не проверена, поскольку Docker Engine не запущен. Проверенный путь — Python из раздела 1.

## 6. Как дать жюри обычную интернет-ссылку

**Загрузка кода в GitHub не запускает Python-сервер. Постоянная публичная версия пока не опубликована.** GitHub Pages раздаёт статические файлы и не заменяет API этого приложения.

Для размещения подготовлены `Dockerfile` и `render.yaml`. Владелец репозитория может подключить его к Render, создать Blueprint из `render.yaml` и дождаться успешного развёртывания. Это действие выполняется в аккаунте хостинга; добавление конфигурации в Git не создаёт сервис автоматически. После размещения проверьте `/`, `/api/v1/health`, PDF и `/miniapp/` на выданном HTTPS-адресе и передайте его жюри. Сервис запускается без внешней AI-модели; если она нужна, храните ключ в настройках сервиса и добавьте `--with-ai` к команде запуска.

Публичный адрес Mini App после такого размещения: `https://<адрес-сервиса>/miniapp/`. Его можно указать в настройках бота. Для самой рассылки бот запускается отдельно по `TelegramBot/README.md` с личным токеном и состоянием подписок; они не публикуются в Git.

Документация: [Render Blueprint](https://render.com/docs/blueprint-spec), [ограничения GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
