# Данные кейса

Три файла из предоставленного командой архива организаторов `data.zip` включены в комплект для проверки жюри:

- `nodes.parquet`: 2 248 узлов;
- `edges.parquet`: 3 119 направленных агрегированных связей;
- `transactions.parquet`: 4 840 транзакций за июль 2026 года.

Это входы расчёта, а не синтетическое демо. GID — идентификатор узла в наборе; персональные сведения по нему не восстанавливаются. В API GID передаётся строкой для сохранения точности.

Готовый результат находится в `backend/jury_snapshot/`. Контрольные суммы исходных файлов записаны в `runs/<run_id>/run.json`; запуск `python jury_start.py --check` сверяет их. Повторный расчёт: `python -m backend.run_pipeline` после установки зависимостей. Новый результат попадёт в отдельную папку `backend/output/`.
