# Graph Engine и OpenAI-ассистент

Реализованная часть Freedom Graph Intelligence по CONTRACT_AI 2.0 и PROJECT 1.1: локальная графовая аналитика и отключаемый OpenAI-агент. Все файлы размещены в `graph/` по запросу владельца проекта. Frontend, основной backend, Telegram и публикация общего снимка остаются у участников команды.

## Запуск из корня репозитория

Python 3.11+. Установка нужна один раз; затем анализ работает без сети.

```console
python -m pip install -r graph/requirements.txt
python -m graph --data ./data --output ./output-graph-check --verify-repeat
```

Папка `data` содержит nodes.parquet, edges.parquet, transactions.parquet. Данные и ключи не включены в Git. `--output` должен указывать на новую папку: предыдущий результат не перезаписывается. Команда создаёт три CSV фиксированной схемы, snapshot.json, run.json и quality_report.json. `--verify-repeat` дополнительно сравнивает все четыре таблицы и байты CSV двух расчётов.

Это самостоятельная проверочная выгрузка нашей части. Команда команды `python run_pipeline.py`, LATEST, last_attempt, общий API и сайт — интеграция владельца backend; здесь они не объявляются реализованными. `analyze()` ничего не записывает.

```python
from pathlib import Path
from graph import analyze, DEFAULT_CONFIG, DataValidationError

result = analyze(Path('data'), DEFAULT_CONFIG)
# nodes, edges, clusters, top: pandas.DataFrame
# run_meta, quality: dict
```

`gid/src/dst` в DataFrame — int64. `result.nodes` содержит все Node и EvidenceDetail как отдельные колонки; также есть вложенный `evidence_detail`. `pass_through=None` при нулевом входе, `temporal=None` (временные исследования не реализованы). `why` заполнен для top-100. Для JSON используйте `graph.serialization.snapshot(result, run)`; идентификаторы преобразуются в строки, не через float. Не извлекайте gid из смешанной числовой строки DataFrame: используйте `itertuples`, `to_dict('records')` или конкретную колонку.

## Методика roles-v1

Все параметры — в `graph/config/methodology.yaml`; явный `config_path` позволяет backend использовать общий `config/methodology.yaml`. Дополнительные параметры помечены в INTEGRATION.md. Не меняйте только копию конфигурации без передачи её в analyze.

Направленный DiGraph включает все узлы до добавления рёбер. Степени — уникальные контрагенты, суммы — наблюдаемые потоки, счётчики — количество транзакций. `pass_through=out_kzt/in_kzt`, при нуле входа null. `seed_reach` — число seed с направленным путём до узла, сам seed не считается своим потомком. Betweenness нормировано, без весов: сумма денег не длина пути. PageRank использует поток и alpha=0.85, в приоритет не входит.

Louvain применяется к неориентированной проекции: встречные суммы складываются, weight=w, resolution=1, seed=42. Исходное направление сохраняется для ролей и путей. Компоненты и кластеры нумеруются по размеру убывающе, затем по минимальному gid. Перед расчётом входы сортируются. Изолят — отдельный кластер. Петли сохраняются в исходных рёбрах и внутреннем обороте кластера, исключаются из структурных метрик с предупреждением.

| Правило | Условие | Сила s |
|---|---|---|
| R_CONS | in_deg ≥ 5 | in_deg/5 |
| R_DIST | out_deg ≥ 10 | out_deg/10 |
| R_TRANS | не seed, вход и выход есть, 0.8 ≤ out/in ≤ 1.2 | 2−abs(out/in−1)/0.2 |
| R_TERM | depth < 4, out_deg=0, in_kzt ≥ 300000 | in_kzt/300000 |
| R_COORD | betweenness ≥ p99, ≥2 других кластеров, ≥2 входящих либо исходящих хабов | минимум отношений признаков к порогам |
| R_PERIPH | остальные | максимум допустимых несработавших сил |

Базовая роль — максимальная сила сработавшего правила; равенство: consolidator, distributor, transit, terminal. Другие сработавшие правила сохраняются. Хабы считаются по базовым ролям; coordinator переопределяет базовую роль, которая остаётся в base_role. Его входящие хабы — consolidator/distributor/transit, исходящие — consolidator/distributor.

У специальных ролей role_score=min(1,s/2), у coordinator — среднее min(1,ratio/2) трёх условий. Если p99=0, это условие даёт ratio=1 (без деления на ноль), остальные два условия обязательны. У периферии score=1−0.5·s_max; недопустимые правила имеют силу 0, отрицательная близость транзита ограничена нулём. У изолятов 0.3. Граница умножает оценку на 0.8. Округление 4 знака. Это эвристическое соответствие правилу, не вероятность.

Приоритет:

```text
raw = .25*pct(in_kzt) + .20*pct(betweenness) + .15*pct(n_nbr_clusters)
    + .15*pct(seed_reach) + .25*role_weight*role_score
seed: raw *= .75
priority_score = raw/max(raw), 6 знаков; если max=0, всем 0
```

`pct=rank(method='max',pct=True)`, у нулей pct=0. Веса ролей: coordinator=1, consolidator=.8, distributor=.7, transit=.6, terminal=.4, peripheral=0. Порядок — score убывающе, gid возрастающе. Вклады до seed-множителя и нормирования записаны в priority_contributions, seed_factor хранится отдельно. why содержит два наибольших вклада, значения признаков и рекомендацию. Evidence детерминирован, ≤200 символов; при сокращении сначала удаляется вторичный факт, ограничения сохраняются.

Гипотезы кластеров выбираются в порядке H_ISOLATED → H_COLLECT → H_FANOUT → H_TRANSIT → H_SMALL → H_NOSEED → H_MIXED по §3.9 контракта. Это гипотезы наблюдаемой структуры.

## Ограничения

На depth=4 terminal запрещён. У seed правило транзита выключено: входящие неполны. `external_inflow` описывает неполноту наблюдений, не нарушение. Ниже 5 000 KZT, межбанковские переводы, остатки и атрибуты клиентов не видны. Дата не позволяет выводы о часах. Разметки нет; accuracy не заявляется. Роли и приоритет — основания для ручной проверки, не вывод о виновности. __MACOSX — служебные метаданные архива и не используется.

## OpenAI-агент

```console
python -m pip install -r graph/requirements-optional.txt
```

Перед запуском backend задайте переменные окружения `ASSISTANT_ENABLED=1`, `OPENAI_API_KEY`, `OPENAI_MODEL`. Модель выбирается владельцем ключа; скрытой модели по умолчанию нет. `.env.example` — образец, файл автоматически не загружается. Ключ не нужно вставлять в код или коммитить.

```python
from graph.assistant import Assistant
agent = Assistant(published_snapshot)
answer = await agent.ask('Кто собирает деньги с #... и #...?')
```

Responses API с function calling реализован по [официальной документации OpenAI](https://developers.openai.com/api/docs/guides/function-calling). SDK импортируется только при включённом агенте. Модель получает вопрос, последние 6 сообщений и ограниченные результаты инструментов; полный снимок и сырые транзакции ей не передаются. `store=False`, повторные запросы SDK отключены. Лимиты: 5 обращений к модели, до 5 инструментов, общий таймаут 30 секунд. Предоставлены 7 инструментов контракта; максимум 20 результатов, 10 исходных gid, глубина 4, пути до 6 рёбер и до 5 маршрутов с бюджетом обхода. Ограниченная выдача помечается truncated.

Общие получатели/источники: пересечение достижимых множеств; если пусто, выдаются кандидаты по числу охваченных источников, затем приоритету с `exact_intersection=false`. Это не утверждение об общем для всех узле. Все инструменты читают копию одного снимка и не меняют роли. Ответ проверяется на неизвестные GID, неподтверждённые числовые токены и запрещённые формулировки. Это не полная проверка смысла ответа: подтверждение аналитиком необходимо; необычное форматирование чисел может отклоняться консервативной проверкой.

Без ключа/флага возвращается assistant_disabled. Прочие сбои — internal, как в контракте. Оригинальные исключения провайдера не возвращаются клиенту. Проверены инструменты и цикл агента на подставном клиенте; живые ответы OpenAI пока не проверены, ключ не предоставлен.

## Масштабирование до миллиона узлов

Точный betweenness и spring-layout на таком объёме непрактичны. Перейти к компактному графовому движку (igraph/graph-tool либо CSR), пакетным агрегатам, приближённому betweenness с зафиксированным seed и отдельной версией методики. Louvain и достижимость распараллеливать/вычислять по компонентам; координаты — иерархически по кластерам. API выдаёт подграфы и страницы, браузер не загружает миллион узлов. Валидация и сверка потоков выполняются порциями; снимки публикуются атомарно владельцем backend. Такие оптимизации сейчас не реализованы.
