# Реализация SPEC_GRAPH_AI (23.09.2026)

Источник требований — переданные пользователем SPEC_GRAPH_AI.md и TASKS_GRAPH_AI.md. Исключение по прямому запросу пользователя: только OpenAI, без NVIDIA и LLM_BASE_URL. Действующий расчёт обязательных ролей сохранён. Поставка — graph/ и ai_agent/ в main; небольшие подключения в backend перечислены ниже.

analyze() не пишет файлы. AnalysisResult.extras — словарь ExtraResult (таблицы, признаки, документы, сводка). В снимке отдельная ветка extras: tables/features/documents. Это сохраняет побайтную неизменность трёх обязательных CSV. ExtraResult не подменяет ни role_score, ни priority_score, ни evidence.

Каждый модуль защищён отдельным обработчиком ошибок; предупреждения идут в quality_report и run.warnings. Неуспех опции не отменяет базовый результат. При отключении extras.enabled расчёт выполняется без опций. Все новые пороги находятся в graph/config/methodology.yaml → extras.

## Явные трактовки неоднозначностей

- В тексте SPEC денежные корзины начинаются с `< 50000`, затем `[50000,200000)`, `[200000,1000000)`, `[1000000,∞)`. Они реализованы буквально. Это даёт 365/62/17 сырых статусов границы вместо контрольных 367/62/15. Причина найдена: контрольные значения используют правые включённые границы (`≤50000` и т. д.). Повторный расчёт с таким закрытием точно даёт контрольные 367/62/15 и 776 вместо 751 узла в первой корзине. Пороги ради чисел не менялись; выбрана формула из текста. В boundary_rates сохранены исходные ставки, в boundary — объединённые корзины. Корзины обозначены d:b: степень d=0/1/2/3 означает 1/2/3–4/5+, сумма b=0/1/2/3 соответствует четырём интервалам выше. Если объединение только вниз всё ещё не даёт 10 наблюдений, ставка null и статус unknown.
- Окно дробления включает даты с разницей от 0 до 7 дней, целиком все транзакции каждого дня. Так получается 46 пар. Полуоткрытое окно семи календарных дат даёт 43; выбор произвольного поднабора транзакций одного дня ошибочно даёт больше. Точности часов нет.
- Цепочка A→B→A допускается; без неё кандидатов 736 вместо 840. Повторные сопоставления дат не переиспользуют входящую транзакцию внутри одной пары рёбер. Это не атрибуция сумм: суммы рёбер и число повторов показываются отдельно.
- Цикл с неубывающими датами — временно допустимая гипотеза, не доказательство возвращения тех же денег. Проверяются все вращения, каноническая запись хранится от минимального GID.
- Перцентили используют rank(method=max,pct=True), нулевая медиана не приводит к делению на ноль. Круглые суммы (65.62%) сами по себе не считаются аномалией.
- flow_retained делится на весь исходный оборот; seed_pairs_retained — на исходное число достижимых пар (12724). Изоляты исключены из n_components, но входят в знаменатель largest_share. Если степень лучше приоритета, данные таблицы показывают это без подгонки.

## Подключение к backend и frontend

Backend содержит только три необходимых места подключения: snapshot.py записывает дополнительные файлы и ветку extras; api.py монтирует graph.integration.extras_api; assistant.py допускает локальный fallback без ключа. Старый backend без импортируемого graph может по-прежнему стартовать в базовом режиме. Собранный frontend коллег сохранён.

Маршруты: /api/v1/nodes/{gid}/card, /boundary и /boundary/{gid}, /temporal/daily, /temporal/events, /routes, /anomalies, /resilience, /gaps, /coverage, /methodology. Нет результата опции — available:false и пустая выдача. Карточка ai=1 пока возвращает template с предупреждением: необязательный второй LLM-пересказ карточки не включён. Все обязательные разделы карточки формируются локально.

Отдельный экран проверки /analysis-extras в приложении ai_agent показывает время, устойчивость, белые пятна, границу, аномалии, карточки и маршруты. /assistant содержит чат с пометкой fallback и журналом. Встраивание этих вкладок и подсветки циклов/удалённых узлов в основной дизайн — задача владельца frontend. Передаваемые поля для подсветки: cycles.path, chains.a/b/c, resilience.removed[].gids; все GID в JSON — строки.

## Запуск

Из корня: `python -m backend.run_pipeline --data "D:/Хакатон ИИ Агент/data" --config graph/config/methodology.yaml`.
Затем `python -m ai_agent --output backend/output --env-file ai_agent/.env --port 8001`.
Открыть /analysis-extras или /assistant. Старые snapshot.json не содержат extras: для новых вкладок нужен новый расчёт. Датасет и .env не загружаются в Git.
