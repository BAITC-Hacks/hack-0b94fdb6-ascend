# Freedom Graph · Telegram Mini App

Mobile-first интерфейс **того же @FreedomGraphbot**. Основной акцент — тёмно-фиолетовый. Без npm-зависимостей, установки программ или изменений в Frontend/backend/AI.

## Уже работает

- Обзор с приоритетными сигналами, счётчиками и анимированным знаком проекта.
- Сигналы: поиск по GID/ID, фильтры «Все», «Приоритет 80+», «В проверке», пустое состояние.
- Граф: направленные связи, выбор узла, перемещение, масштаб и возврат ко всему графу.
- Карточка сигнала: приоритет, источник/получатель, объяснение, входящие/исходящие связи, кластер, переход на граф.
- Отметка «В проверке» и её снятие: только sessionStorage демонстрации, **не состояние бота/банковского расследования**.
- Русский, казахский и английский языки.
- Telegram WebApp SDK: ready/expand, цвет оболочки, safe-area, BackButton, лёгкий haptic feedback. Работает и в обычном браузере при отсутствии SDK.
- Клавиатурная навигация, подписи кнопок, нативный dialog, prefers-reduced-motion, остановка анимации при скрытии вкладки.

## Статус интеграции

Это функциональная frontend-демонстрация Mini App с **синтетическими данными**, не подключённый AML-клиент. Идентификация, подписки и история Telegram-бота не передаются в страницу. `initDataUnsafe` не используется для авторизации, токен бота и код команды отсутствуют в HTML/JS. Перед реальным подключением нужен серверный слой проверки подписи и срока `Telegram.WebApp.initData`, проверка активной подписки и индивидуальных прав на каждое действие. Эта задача не реализует такой backend.

## Локальный просмотр

На другом компьютере сначала получите репозиторий (нужен доступ к командному GitHub):

```sh
git clone https://github.com/BAITC-Hacks/hack-0b94fdb6-ascend.git
cd hack-0b94fdb6-ascend
```

Если репозиторий уже есть, обновите свою рабочую копию ветки `main`, предварительно сохранив собственные изменения. Повторно клонировать поверх существующей папки не нужно.

Из корня репозитория:

```sh
python3 -m http.server 5175 --bind 127.0.0.1 --directory TelegramBot/miniapp
```

На Windows с установленным Python вместо `python3` можно использовать `py`. Для просмотра Mini App не нужны токен бота, backend, npm или установка пакетов.

Откройте http://127.0.0.1:5175/. Сервер должен отдавать **только miniapp/**, никогда TelegramBot целиком: там находятся .env и база подписчиков.

Это адрес на компьютере, где запущена команда. Держите терминал открытым; остановка — `Ctrl+C`. Если порт занят уже работающим предпросмотром, откройте существующий адрес, а не запускайте второй сервер. Из Telegram на телефоне этот локальный адрес недоступен. Для этого нужен этап публикации ниже. Никакой публичный туннель, открытие порта роутера или изменение firewall для локального просмотра не требуется.

## Передача тимлиду: как устроено и что подключать

### Перенос бота на другой компьютер

Код переносится через GitHub, но локальные `TelegramBot/.env` и `TelegramBot/state/` намеренно не включены. Токен передавайте владельцу запуска отдельно по защищённому каналу, никогда через коммит. Без переноса базы подписчики и история рассылок автоматически не восстановятся.

Текущий Python-бот рассчитан на macOS/Linux (использует `fcntl`); на Windows нужен WSL/Linux. Для первичной настройки и запуска из корня репозитория: `python3 -m TelegramBot.launch`. Настройка запросит токен скрытым вводом и создаст локальную конфигурацию. Новый код активации потребует повторной активации пользователей. Параметры backend и постоянный HTTPS-адрес Mini App задаются в локальном `.env`; подробности — в [README бота](../README.md) и разделах ниже.

**Перед запуском того же токена на компьютере тимлида остановите экземпляр на прежнем компьютере.** Два одновременно работающих процесса `getUpdates` будут конфликтовать. Временный туннель старого компьютера не переносится вместе с GitHub — для независимой работы опубликуйте Mini App по инструкции ниже.

### Два независимых процесса

| Часть | Что делает сейчас | Где находится состояние |
| --- | --- | --- |
| Mini App | Показывает синтетические сигналы и граф, фильтрует их, открывает объяснения | `data.mjs`; язык и отметки только в `sessionStorage` браузера |
| Telegram-бот | Активирует личные подписки, сравнивает опубликованные backend-снимки и рассылает новые связи | `TelegramBot/state/bot.sqlite3` на компьютере с ботом |

Поток Mini App: `index.html` → `app.mjs` → `data.mjs` + `i18n.mjs` + `icons.mjs`. Стили — `styles.css`, знак проекта — `assets/mark.svg`. Сборщик не нужен: браузер загружает ES-модули напрямую. Скрипт Telegram подключён с официального домена; в обычном браузере приложение работает без Telegram-окружения.

Поток бота: Telegram `getUpdates` → проверка активации пользователя → локальная подписка. Независимо от сообщений, бот периодически читает backend (`overview`, `graph`, повторный `overview`), сравнивает согласованные снимки и отправляет новые события активным подписчикам. Первый снимок — база без рассылки. Бот не создаёт и не обновляет расчёты backend.

**Кнопка «Взять в проверку» в Mini App сейчас не вызывает backend и не отправляет команду боту.** Это демонстрационная отметка. Публикация страницы не меняет этого поведения и сама по себе не подключает реальные данные.

### Быстрая публикация демонстрации на Render

1. Получить последнюю командную версию из GitHub. Создать **Static Site**, а не Python Web Service. При необходимости администратор организации разрешает Render доступ к репозиторию.
2. Указать ветку `main`, **Root Directory**: `TelegramBot/miniapp`.
3. **Build Command**: `true` (сборка не требуется), **Publish Directory**: `.`. Если интерфейс предлагает установку зависимостей, её не нужно добавлять: npm-пакетов здесь нет.
4. После публикации открыть выданный HTTPS-адрес. Проверить, что `styles.css`, `app.mjs`, `data.mjs`, `i18n.mjs`, `icons.mjs` и `assets/mark.svg` возвращаются без 404. Сервер должен отдавать `.mjs` как JavaScript, а не как HTML.
5. Передать HTTPS-адрес владельцу запущенного @FreedomGraphbot. Не передавать токен через README, GitHub, скриншоты или общие чаты.

Можно использовать другой статический хостинг с HTTPS: код от Render не зависит. Не выставляйте заголовок `X-Frame-Options: DENY` без проверки Telegram Web: он может мешать встраиванию. Если на хостинге настроена CSP, разрешите загрузку SDK с `https://telegram.org` и проверьте открытие из нужных клиентов Telegram.

### Подключение опубликованного адреса к тому же боту

Владелец бота добавляет **только в локальный** `TelegramBot/.env`:

```dotenv
MINIAPP_URL=https://адрес-вашего-mini-app
```

Это пример, а не готовый адрес. Укажите фактический адрес, выданный хостингом. Из корня репозитория:

```sh
python3 -m TelegramBot --configure
```

Команда проверяет, что токен принадлежит @FreedomGraphbot, и настраивает кнопку меню через `setChatMenuButton`. Затем остановите старый процесс бота через `Ctrl+C` в его терминале и запустите один новый процесс:

```sh
python3 -m TelegramBot
```

Перезапуск нужен, чтобы сообщения `/start` и `/status` тоже получили новую inline-кнопку. Уже отправленные старые сообщения автоматически не меняются — запросите `/status` после активации. Если приложение Telegram показывает старое меню, закройте и снова откройте чат. Для быстрой проверки самого опубликованного интерфейса его HTTPS-адрес можно открыть в браузере, независимо от работы процесса бота.

### Подключение реальных данных — отдельная задача интеграции

Тимлид и владелец backend должны согласовать и реализовать:

- серверную проверку подписи и срока действия `Telegram.WebApp.initData` по официальному алгоритму; нельзя доверять ID, присланному обычным JSON, или одному `initDataUnsafe`;
- проверку активации и прав пользователя на сервере при чтении сигналов и при сохранении отметки; наличие публичной кнопки меню не даёт доступа;
- API для пользовательских сигналов/связей и отметок проверки; сейчас Mini App к такому API не обращается;
- разрешение на передачу данных организаторов/банка, выбор полей, защиту доступа и хранение секретов только на сервере;
- передачу подготовленного результата анализа основной системе: исходные parquet и рассчитанные снимки не появляются на хостинге автоматически из этого Mini App;
- устойчивое хранение базы подписчиков и очередь доставки, если сам бот переносится с ноутбука. Обычный статический хостинг Python-бота не запускает.

До этого оставьте метки DEMO и синтетические данные. Токен, уже опубликованный в переписке, замените перед подключением чувствительных данных.

### Чек-лист перед показом жюри

- HTTPS-адрес открывается с другого устройства, оформление и SVG-иконки загружаются.
- RU / KZ / EN переключаются; на мобильном экране нет горизонтальной прокрутки.
- Поиск `192831` находит две связи, неизвестный GID показывает пустое состояние, сброс возвращает список.
- Фильтр «Приоритет 80+» показывает два тестовых сигнала.
- Карточка содержит «Почему стоит проверить»; отметка меняет счётчик и фильтр «В проверке», снятие отметки работает.
- «Показать на графе» открывает выбранный маршрут; масштаб, перемещение и «Весь граф» работают.
- Кнопка меню открывает этот же Mini App внутри @FreedomGraphbot.
- Жюри явно объяснено, что здесь демонстрационный интерфейс, а не завершённая интеграция с банковскими данными.

Документация публикации: [Render Static Sites](https://render.com/docs/static-sites). Подключение: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [проверка initData](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app), [setChatMenuButton](https://core.telegram.org/bots/api#setchatmenubutton).

## Открытие внутри Telegram

Нужен публичный HTTPS-адрес статической папки `miniapp/` (index.html, styles.css, файлы .mjs, assets/mark.svg). Постоянный хостинг пока не настроен. Для текущего показа подключён временный HTTPS-туннель localhost.run к локальному `127.0.0.1:5175`; его адрес сохранён только в локальном `TelegramBot/.env` как `MINIAPP_URL` и назначен кнопке меню @FreedomGraphbot.

**Временная кнопка зависит от ноутбука.** Должны работать локальный HTTP-сервер и SSH-туннель, а для ответов на команды — также процесс бота. Сон ноутбука, закрытие процесса или смена адреса туннеля разрывают доступ. Бесплатный адрес может меняться: после смены нужно обновить `MINIAPP_URL`, повторить `--configure` и перезапустить бота. Публично открыт только каталог Mini App с синтетическими данными; `.env` и SQLite не публикуются. Эта временная ссылка не заменяет постоянный адрес общего проекта для проверки жюри. Тимлид должен выполнить публикацию выше и заменить адрес кнопки.

Использован встроенный SSH без установки программ и без передачи личных SSH-ключей. Ограничения временных адресов: [localhost.run Free Tier](https://localhost.run/docs/forever-free/).

После публикации владелец сохраняет `MINIAPP_URL=https://…` в локальном TelegramBot/.env, запускает `python3 -m TelegramBot --configure` и перезапускает бота. Команда добавляет пункт меню Mini App тому же @FreedomGraphbot. Кнопка web_app также появляется в приветствии и статусе активированного пользователя. Не используйте localhost в MINIAPP_URL: телефон пользователя не сможет открыть ваш ноутбук.

Пункт меню ведёт на публичную **демонстрацию**; наличие кнопки не является проверкой банковского доступа. Не заменяйте mock на чувствительные данные без серверной авторизации. Токен, опубликованный в переписке, необходимо заменить перед использованием с реальными данными.

## Визуальная система и иконки

Фон `#100D18`, панели `#191421`, линии `#30263E`, основной акцент `#69429E`, светлый акцент `#B99AE8`. Зелёный не используется в брендинге. Красный/оранжевый/жёлтый/зелёный/голубой остаются небольшими метками уровней приоритета; они не означают доказанное нарушение.

Основные кнопки:

| Действие | Оформление | Иконка |
| --- | --- | --- |
| Посмотреть сигналы | Фиолетовая заливка, светлый текст | Стрелка вправо |
| Взять в проверку | Главная кнопка карточки | Галочка |
| Показать на графе | Тёмная заливка, тонкая рамка | Три соединённых узла |
| Все / Приоритет 80+ / В проверке | Компактные фильтры с выбранным состоянием | Текст; без перегрузки |
| Открыть бота | Вторичная кнопка | Переход наружу |
| Приблизить / Отдалить / Весь граф | Квадратные кнопки с подписями для screen reader | Плюс / минус / рамка |
| Обзор / Сигналы / Связи | Нижняя навигация | Плитки / колокольчик / граф |

`icons.mjs` — 22 масштабируемые SVG-иконки общего стиля; `assets/mark.svg` — фиолетовый знак F с графом. PNG для интерфейсных кнопок не нужны: SVG чётче на разных экранах. Новые изображения заказывать не требуется. Если нужен дополнительный маркетинговый набор: квадратная иконка приложения, обложка профиля бота и три иллюстрации для пустого состояния/успешной активации/проверки сигнала. Это необязательные материалы, пока не созданы.
